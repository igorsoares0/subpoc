1Supertitle — proposta de redesign · direção "Estúdio editorial" · v2 conferida com o código · UI em inglês
1aDireção visual, sistema e princípios de UX
SUPERTITLE · REDESIGN 2026
Estúdio
editorial.

Uma mistura de clean/moderno na interface com toques editoriais nos momentos de marca. A UI fica neutra e silenciosa para o vídeo ser o protagonista; a serifa dá personalidade e a cor única funciona como um marca-texto.

Legenda é texto — então tratamos a transcrição como um documento, não como uma lista de cards.

Hoje
01Preto OLED + azul padrão do Tailwind: correto, mas sem identidade. 02Hierarquia plana — todo rótulo é caixa-alta cinza, tudo pesa igual. 03"Styles" é uma rolagem única com 20+ controles; difícil achar o que mudar. 04A timeline só mostra o vídeo — os blocos de legenda não aparecem nem são arrastáveis. 05Idioma misturado (Cortar, Export, Render) — padronizar tudo em inglês.
